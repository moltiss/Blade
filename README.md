
# Blade

## Назначение программы

Blade — средство предварительного шифрования текста, разработанное в рамках учебного проекта по защите информации.

Программа обеспечивает шифрование текстовых сообщений на стороне клиента перед их отправкой на сервер.

## Основные возможности

- Шифрование и расшифрование текстовых сообщений.
- Регистрация и аутентификация пользователей.
- Авторизация с использованием JWT.
- Привязка учётной записи к цифровому отпечатку устройства.
- Настраиваемая политика сложности паролей.
- Ограничение количества попыток входа.
- Хранение истории зашифрованных сообщений.
- Журналирование событий безопасности.
- Контроль целостности и подлинности файлов.
- Безопасное обновление программного обеспечения.
- Графический интерфейс в тёмной теме.

## Используемые технологии

| Технология | Назначение |
|---|---|
| Python | Язык программирования |
| PySide6 | Графический интерфейс |
| Flask | Сервер REST API |
| SQLite | Хранение данных |
| AES-256-GCM | Шифрование сообщений |
| PBKDF2-HMAC-SHA256 | Выработка ключей и хэширование паролей |
| SHA-256 | Контроль целостности |
| ECDSA P-256 | Проверка подлинности файлов |
| Ed25519 | Проверка подписи обновлений |
| JWT HS256 | Авторизация пользователей |
| CycloneDX SBOM | Контроль состава зависимостей |
| PyInstaller | Сборка исполняемых файлов |

## Архитектура проекта

Blade имеет клиент-серверную архитектуру.

Клиент выполняет шифрование и расшифрование сообщений, а сервер обеспечивает аутентификацию, хранение шифротекстов, журналирование и распространение обновлений.

## Структура проекта

- `client/` — клиентская часть приложения.
- `server/` — серверная часть приложения.
- `tools/` — инструменты сборки, подписания и тестирования.
- `demo_offline/` — материалы демонстрационного обновления.
- `requirements.txt` — зависимости проекта.
- `.gitignore` — правила исключения служебных и конфиденциальных файлов.

Закрытые ключи, базы данных пользователей, секреты JWT и локальные журналы не публикуются в репозитории.



## Установка и запуск

### Системные требования

- Windows 10/11.
- Python 3.13 или 3.14 с совместимыми версиями библиотек.
- Доступ к серверной части приложения.

### Установка зависимостей

```bash
python -m venv .venv
```

После активации виртуального окружения:

```bash
python -m pip install -r requirements.txt
```

Для запуска необходимо подготовить конфигурационные файлы
config.ini клиента и сервера. Локальные конфигурации
не включены в публичный репозиторий.

### Запуск сервера

```bash
cd server
python app.py
```

Сервер по умолчанию доступен по адресу:

http://127.0.0.1:5000

### Запуск клиента

В отдельном терминале из корневой папки проекта:

```bash
python client/main.py
```

## Механизм безопасного обновления

Blade поддерживает два режима обновления:

- Онлайн — получение пакета обновления через REST API.
- Офлайн — установка локального подписанного пакета.

Процесс безопасного обновления включает:

1. Проверку цифровой подписи манифеста Ed25519.
2. Проверку минимальной поддерживаемой версии.
3. Проверку контрольной суммы SHA-256.
4. Проверку состава зависимостей SBOM.
5. Распаковку обновления в staging.
6. Завершение работающего приложения.
7. Создание резервной копии backup.
8. Замену файлов приложения.
9. Проверку запуска новой версии.
10. Откат при ошибке запуска.
11. Запись результата в журнал аудита.

Для установки обновления используется отдельный
исполняемый файл BladeUpdater.exe.
